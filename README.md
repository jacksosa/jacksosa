## About

20+ years building high-performance backend systems in Java and the Spring ecosystem, across domains where reliability under load is non-negotiable: investment banking, capital markets analytics, national smart metering infrastructure, and government digital services.

Current engagement at **DWP Digital** modernising the New Style Jobseeker's Allowance platform — a Spring Boot / Kafka / MongoDB system managing the full claimant journey for millions of UK citizens, structured around Hexagonal Architecture for long-term maintainability and policy agility.

The work that most clearly defines my specialism is a production automated trading framework built for the **Betfair Exchange** — a Spring Boot event-driven system consuming live market data via the Streaming API and executing strategies driven by a proprietary signal engine covering Weight of Money, Last Traded Price dynamics, price velocity, and order flow imbalance. It runs headlessly on AWS with built-in reconnection, state recovery, per-market risk controls, and structured observability.

I contract through **Trinity Logic**, working remotely with distributed engineering teams. If your project involves Betfair, Betdaq, Smarkets, or Matchbook integration, you've found the right engineer.

## What I Build

**Betting exchange platforms** — Production Java systems integrated with Betfair's Exchange and Streaming APIs: full order lifecycle management, real-time signal evaluation, automated strategy execution, pre-race and in-play market handling, and risk controls built directly into the execution layer.

**Event-driven microservices** — Spring Boot services over Apache Kafka and RabbitMQ, designed for idempotent, fault-tolerant processing at scale — where exactly-once business outcomes and safe reprocessing under failure matter more than benchmark throughput.

**Serverless AWS data pipelines** — API Gateway / SNS / SQS / Lambda ingestion architectures with cross-region disaster recovery, provisioned as code via CDK and Ansible-templated CloudFormation, operating without data loss under any failure condition.

**Legacy modernisation at scale** — Replacing constrained legacy systems with Hexagonal Architecture microservices, isolating domain logic from infrastructure concerns to produce platforms that can evolve safely as policy and requirements change — demonstrated at national scale on DWP Digital's JSA platform.

**Multi-protocol data integration** — REST, SOAP, and GraphQL adapters; Java and Python enrichment pipelines into Apache Druid and Kafka; scheduled data warehouse ingestion combining operational and analytical data from fragmented third-party systems.

**Mission-critical backend delivery** — Production experience across investment banking (UBS Warburg), capital markets analytics (Mosaic Smart Data), smart metering infrastructure (ESG Global), and national-scale government services (DWP Digital).
